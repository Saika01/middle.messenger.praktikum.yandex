### О проекте

Учебный проект - мессенджер.
Веб-приложение для обмена сообщениями с системой аутентификации пользователей.

# Как установить и начать пользоваться

`npm install` -> `npm run start`

# Команды

`npm run build` - собирает проект,
`npm run preview` - предпросмотр проекта,
`npm run start` - собирает и запускает проект (включает в себя команды npm run build и npm run preview),
`npm run update:scss` - обновляет файлы .css в соответствии с соответствующими файлами .scss.

# Взаимодействие с проектом

### Страница входа (/)
- При первом посещении сайта открывается форма для авторизации
- Если введенные данные не соответствуют ни одному пользователю, происходит перенаправление на страницу регистрации (/sign-up)
- При успешной аутентификации пользователь перенаправляется на страницу сообщений (/messages)

### Страница сообщений (/messages)
- **Создание чата**: кнопка "+" в левом верхнем углу открывает модальное окно для ввода названия нового чата
- **Просмотр профиля**: кнопка "Профиль" осуществляет переход на страницу /profile
- **Просмотр чатов**: список доступных чатов отображается в левой колонке, клик по чату открывает его
- **Работа с сообщениями**: возможность отправки сообщений в открытый чат
- **Управление участниками чата**: через меню (троеточие в правом верхнем углу) можно добавлять и удалять пользователей из чата

### Страница профиля (/profile)
- Отображение данных пользователя (в текущей версии используются моковые данные)
- **Кнопка "Изменить данные"**: переход на страницу /settings для редактирования информации пользователя и смены аватара
- **Кнопка "Изменить пароль"**: переход на страницу /change-password
- **Кнопка "Выйти"**: завершение сессии и переход на страницу входа (/)

### Страница с ошибкой (/505 или /404)
- Кнопка Назад к чатам: переход на страницу /messages

### Навигация
- На большинстве страниц присутствует кнопка "Назад" в виде серой панели со стрелкой слева экрана
- Функциональность кнопки аналогична кнопке "Назад" в браузере

## Технические особенности
- Система аутентификации пользователей
- Возможность создания и управления чатами
- Функциональность обмена сообщениями в реальном времени
- Редактирование профиля пользователя
